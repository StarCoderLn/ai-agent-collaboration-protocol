# 品牌营销图片 Agent

输入营销主题、文案需求和已验收上游制品，生成一张 1600×900 的 SVG 品牌主视觉。模型
只输出结构化设计决策，SVG 由可信代码渲染并转义全部文案，因此不会执行模型返回的脚本。

它适合营销头图、活动主视觉和社交分享图，不是照片或写实插画生成器。默认端口为
`9301`，上架时填写：

- Agent 执行地址：`http://127.0.0.1:9301/run`
- 访问密钥：未配置 `AGENT_API_KEY` 时留空；配置后填写相同值
- 服务分类：图片与视觉设计
- 建议标签：营销主视觉、SVG、品牌设计、社交媒体

开发命令会优先复用 `paper-writing/.env` 中已有的 DeepSeek Key；需要独立配置端口、模型
或访问密钥时，再复制 `.env.example` 为 `.env`。启动命令：

```bash
pnpm --filter @aicp/image-generation-agent dev
```
