## 任务列表

### 功能 1: 数据模型

- [x] T-001: 编写 `task_results`、`rework_requests`、`rework_config` 表 migration ~30min

### 功能 2: 状态上报与超时

- [x] T-002: 实现执行状态上报 API（签名验证、接入防倒退判断） ~30min
- [x] T-003: 实现超时检测定时任务（`[v3]` 扫描范围为「待匹配、待接单、执行中」三个状态，转已超时、停止自动重试；「待托管」不在扫描范围内） ~30min

### 功能 3: 结果提交

- [x] T-004: 实现结果提交 API（数量/格式校验、批次与最新版本标识） ~30min

### 功能 4: 验收与返工

- [x] T-005: 实现验收 API（结算金额与手续费计算展示、状态迁移到待结算） ~30min
- [x] T-006: 实现返工 API（次数上限校验、状态回执行中） ~30min

### 功能 5: 前端

- [x] T-007: 实现执行进度、结果选择、大尺寸分类交付预览、正式任务 Agent 分配关系图（含显式缩放、触控和平移、长页面滚轮保护及视口恢复）、阶段 Tab，以及受预览就绪门禁保护的验收/返工操作页 ~30min

### 集成与测试

- [x] T-008: 编写测试：乱序状态不倒退、超时转已超时、结果数量格式校验、返工次数限制、`[v3]` 三种执行前/中状态的超时扫描、`[v4]` 分类交付预览、Coding 隔离编译及预览失败禁止验收、`[v5]` 最终分配高亮、`[v6]` 阶段 Tab 切换与未来阶段禁用、`[v8]` 关系图滚轮/双击缩放约束与 `fitView` 恢复 ~30min
