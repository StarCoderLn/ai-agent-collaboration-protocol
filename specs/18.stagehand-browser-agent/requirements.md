# Stagehand Browser Agent — 需求

## 目标

在不改变平台任务、资金和 DAO 权威状态的前提下，增加一条可上架的公开网页研究能力，
并用少量自然语言页面检查补充现有确定性测试。

## 功能需求

1. [F-001] Agent 必须复用 AICP 快速 HTTP 协议，并交付 Markdown 与版本化 JSON 两种产物。
2. [F-002] 只访问任务正文中明确给出的 HTTP(S) URL，一次最多 5 个域名、20 个页面。
3. [F-003] 拒绝本机、私网、非标准端口、DNS 非公网结果和未授权跨域重定向。
4. [F-004] Stagehand 必须使用 Zod Schema 提取摘要、关键事实和原文摘录，并保存最终 URL 与访问时间。
5. [F-005] LangGraph 必须逐页推进；单页失败记录稳定错误后继续，已完成来源不得丢失。
6. [F-006] 每个任务使用独立无登录浏览器，禁止下载，服务默认最多运行一个浏览器任务。
7. [F-007] 网页内容不得触发登录、表单提交、购买、删除、资金、DAO 或数据库写入。
8. [F-008] 自然语言页面冒烟只读本机页面，不替代固定选择器、金额与状态断言。
9. [F-009] Stagehand 必须通过官方 ClientLLM 复用现有 DeepSeek 配置，校验供应商响应且不泄露原始错误正文。
10. [F-010] 网页调研助手必须进入平台 Agent 目录，并由本地 Anvil 与 Sepolia 启动器共同管理目录同步、认证配置和进程生命周期。

## 验收标准

- [x] [AC-001] URL/DNS/重定向边界、逐页成功与失败、产物和单并发测试通过。
- [x] [AC-002] Browser Agent 类型检查、单包测试和生产构建通过。
- [x] [AC-003] Stagehand 4.1 本地 Chromium 真实初始化并读取固定页面，不调用模型或外部网络。
- [x] [AC-004] 使用真实 DeepSeek 访问 `example.com`，结构化来源、事实、引文和时间均已核对。
- [x] [AC-005] 在运行中的 AICP `/tasks` 页面完成 `observe` + `extract` 自然语言冒烟。
- [x] [AC-006] 当前 Agent 市场展示网页调研助手，详情、分类、价格与 9304 健康接口均已核对。
- [x] [AC-007] 从市场发布研究任务，经匹配、1.5 USDC Sepolia 托管、派发、真实 DeepSeek 执行、双格式交付、人工验收和链上结算完成平台闭环。

本机代理会把部分公网域名映射到 `198.18.0.0/15` 网络桥接地址。正式 SSRF 策略不会直接
放行该保留网段：仅当系统 DNS 的全部结果都落在该网段时，才通过固定 Cloudflare HTTPS
DoH 复核真实 A/AAAA；复核失败、私网结果或混合结果仍会拒绝。真实 Chromium 导航、页面
读取和 DeepSeek 提取均未替换。

AC-007 的真实验收任务为 `21866706-821b-4814-be74-96727086dd2f`。网页调研助手读取 Stagehand
与 Playwright 官方文档并交付 Markdown 和 `aicp.browser-research.v1` JSON；Sepolia 托管交易为
`0x6081778f3cea28be5b42832b7197dfc17b08d1d7889c0beaaeb4274b483f60fc`，最终原子结算交易为
`0x1177d2e6e4386b674aa129cee479355828a8a4322f582b6df54f9a954a5b75f3`。页面与链上同步确认总额
1.5 USDC、平台服务费 0.05 USDC、Agent 实收 1.45 USDC，任务最终状态为 `settled`。

AC-005 在 `http://127.0.0.1:3001/tasks` 完成：`observe` 返回 3 个候选控件，`extract`
确认发布入口可见；QA 强制初始与最终 URL 都是回环地址，并在所有退出路径关闭 Chromium。

## 非目标

- 不自动搜索互联网或自行扩展任务域名。
- 不接管既有 Playwright/Vitest、平台工作流、Temporal、资金或 DAO 状态机。
- 不保存或复用用户浏览器登录态。
- 不在本轮部署 Browserbase、AWS 或其他云端浏览器基础设施。
