## 任务列表

### 功能 1: 状态机与数据模型

- [x] T-001: 定义任务主状态机（含 `[v9]` `draft → planning → awaiting_escrow`、全部执行状态与异常分支的迁移表、可辨识联合）与 `TransitionTaskStatus()`，并编写 `tasks`、`categories`、`tags`、`[v2]` `attachment_category_limits`、`[v3]` `platform_fee_config`、`[v4]` `task_timing_config` 及 `[v9]` 托管前选择字段 migration ~30min

### 功能 2: 分类标签服务

- [x] T-002: 实现分类树查询与标签建议/同义词归一 API ~30min

### 功能 3: 创建任务 API

- [x] T-003: 实现共享校验规则定义（截止时间、计价兼容、标签禁用词、`[v2]` 分类附件边界、`[v4]` 截止时间配置；`[v10]` 正式发布允许计价为空） ~30min
- [x] T-004: 实现 `POST /api/tasks`、`PATCH /api/tasks/:id`、`POST /api/tasks/:id/submit`（`[v9]` 提交事务同步创建正式工作流；`[v10]` 服务端自动识别规范能力） ~30min
- [x] T-005: 实现 `CalculatePlatformFee()`（`[v3 新增]`，唯一权威手续费计算函数）与 `GET /api/tasks/:id/preview` 预览接口（费用计算、不可逆提示） ~30min

### 功能 4: 前端

- [x] T-006: `[v10 修改]` 实现快速发布表单（任务标题、可选补充说明、服务分类、截止日期），移除技能标签与固定预算；空补充说明复用标题，高级设置保持折叠，提交失败自动定位首个错误字段 ~30min
- [x] T-007: 实现发布预览页 ~15min

- `[2026-09-06 增量]` 发布页增加关键主题缺口提示；按用户确认移除自由发挥选项及自动追加授权文案，仅传递原始说明或标题。新工作流移除默认 PRD，原始合同输入与旧已验收 PRD 显式区分。规划与表单回归已验证，旧选择/托管/执行 PostgreSQL 回归通过；未重新执行真实模型与钱包闭环，不扩大既有验收证据。
