- 当前自动准入方案仅依赖 Feature 1、2、3，不再等待 `14.T-001` RBAC 或人工审核；版本记录中的等待说明仅反映 2026-08-24 的历史方案。
- T-002 依赖 T-001 与 `1.T-008` 的沙箱协议标记。
- T-003 依赖 T-002；T-004 依赖 T-003 与 `3.T-004` 的权威状态机。
- T-005 依赖 T-004 与 [[2.agent-registration]] 的 SIWE 身份和 Agent 归属。
- T-006 覆盖 T-002 至 T-005 的关键正常、失败与恢复路径。
