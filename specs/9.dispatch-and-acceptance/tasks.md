## 任务列表

### 功能 1: 数据模型与原子占用

- [x] T-001: 编写 `task_assignments`（任务/工作流节点活跃唯一约束）、`dispatch_attempts` 表及 `[v2]` workflow selection、冻结总价字段 migration ~30min
- [x] T-002: 实现托管前或无 txHash/链事件失败后的 `SelectWorkflowCandidate()`（含单阶段替换、总价与失败 intent 金额原子重算）及托管后 `LockAssignment()`；选择只记录当前快照报价，分配才原子占用 Agent ~30min

### 功能 2: SQS 派发

- [x] T-003: 实现 SQS 派发生产者（幂等键；按模式使用 HMAC 或可选 Bearer Token）；正式工作流只在托管确认且 DAG 依赖满足后派发冻结选择 ~30min
- [x] T-004: 实现 HMAC Agent 接单/拒单回调与快速 Agent 同步产物确认；快速结果先持久化，内部转交可恢复且不重复调用 Agent ~30min

### 功能 3: 超时处理

- [x] T-005: 实现接单超时扫描任务（标记接单失败、任务回待匹配） ~30min

### 功能 4: 前端

- [x] T-006: 实现托管前候选选择/准确总价展示、已选关系图收敛、按阶段重新选择及托管后分配状态展示 ~30min

### 集成与测试

- [x] T-007: 编写测试：选择与托管边界、幂等与并发、接单超时，以及快速 HTTP 产物校验、无密钥/Bearer 调用、同步结果持久化、内部转交恢复不重复外部调用和历史 HMAC 回归 ~30min
